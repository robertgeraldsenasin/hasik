# ADR-0003: Project name "Hasik"

- Status: Accepted
- Date: 2026-10-29

## Context

The working titles "Sungka AI" and "Sungka Arena" are generic and likely to clash
with existing apps; the spec requires an original name.

## Options

Hasik ("to sow"), Sigay (cowrie shell), Kabibe (seashell).

## Decision

**Hasik**: Tagalog for "to sow". Sowing is the single move in Sungka, so the name
says what the game is about, and it is short, memorable and Filipino.

## Consequences

Repository `hasik`, packages `@hasik/*`, site title "Hasik". "Sungka" stays in the
tagline and description so the project is still found by people searching for it.
The design spec in `docs/spec/` keeps its original "Sungka Arena" wording as a
historical document.
